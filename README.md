# EARTH-211-Project

Investigating the Validity of Predicting Atlantic Hurricane Strength with Ocean Surface Temperature

Research question: _Have hurricanes developing in the Atlantic Main Development Region been increasing in intensity over the last 50 years (1975-2024)? How does ocean warming due to climate change and variations in water temperature over time affect the strength of developing hurricanes?_

This project investigates the relationship between hurricane intensity, quantified by windspeed, and the temperature of the water over which the hurricane formed. It uses several statistical analysis methods including time series analysis, time series decomposition, linear regression, t-test for means, and Chi-squared test for independence. These methods serve to offer insight on the relationship between windspeed and water temperature, and explore whether hurricanes have been getting stronger since 1975 to the present day. 

Data Sources:
NOAA NHC HURDAT2: https://www.nhc.noaa.gov/data/#hurdat
NOAA NCEI Atlantic MDR land and ocean temperature time series: https://www.ncei.noaa.gov/access/monitoring/climate-at-a-glance/global/time-series/atlanticMdr/land_ocean/tavg/1/0/1975-2024

Repository Structure:
01_RawData contains the raw datasets downloaded from NOAA's websites. This data has not been altered or processed.
02_ProcessedData contains the processed version of HURDAT2 uploaded by a user online. It also contains the complete processed data file that combines date, hurricane windspeed, and water temperature data. This is the dataset I worked off of during the project.
03_Figures contains all the figures I created for the project.
04_Tables contains all the tables I created for the project.
05_References contains all the references used for the project.
06_FinalReport contains a PDF file of the final report.
